Как запустить проект?

Компилятор с поддержкой C++
Система сборки "CMake"
Библиотека OpenCV
В качестве удобной IDE, можете выбрать QtCreator, CLion или же VisualStudio

В чём суть работы? 
Данная программа может отслеживать сразу несколько лиц в одном видеопотоке и записывать видео, которые будут сохраняться локально на устройстве. Сохранённое видео представляет из себя по кадрого каждое лицо, которое было отслеженно программой
