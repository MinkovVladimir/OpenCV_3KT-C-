Как запустить проект?

Компилятор с поддержкой C++
Система сборки "CMake"
Библиотека OpenCV
В качестве удобной IDE, можете выбрать QtCreator, CLion или же VisualStudio

В чёс суть работы? 
Данная программа может отслеживать сразу несколько лиц в одном видео потоке и записывать видео, которые будут сохраняться локально на устройстве. Сохранённое видео представляет из себя по кадраго каждое лицо, которое было отслежино программой
